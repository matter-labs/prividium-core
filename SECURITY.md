# Security Policy

We truly appreciate efforts to discover and disclose security issues responsibly!

## Reporting a vulnerability

Email [security@matterlabs.dev](mailto:security@matterlabs.dev).

We take an impact-first approach rather than a rules-first one. If you believe you have found an impactful issue, report
it even if you are unsure whether it qualifies.

Please do not open a public issue for a security report.

## Scope

This policy covers this repository.
